# 06 · 无限画布专题

> 研究组：无限画布/大模型/变现 · 18次检索 · 网站对应模块：无限画布

## 一、定义与核心价值

无限画布 = 无固定边界、可无限平移缩放的AI编辑画布：多张生成图/参考图/文本作为"节点"自由摆放连线互相引用，生成（文生图/图生图/扩图/局部重绘）与手工编辑在同一平面连续进行，形成"生成-参照-再生成"循环。

对漫剧的四大价值：
1. **分镜连绘**：前一镜成品图直接作为下一镜构图/尾帧参考，按时间线铺开——"决定长片一致性与效率的核心载体"
2. **角色一致性**：三视图/定妆照钉在画布当"身份锚点"，锁定五官服饰肤色参数后切换任意模型数十镜头不崩
3. **场景延展**：outpainting把单张场景图扩成同一世界观多角度场景库（选型建议：从≥2场景≥3角色的项目入手，参考图是最有效锚点）
4. **多格故事版**：自由排版多格画面，每个分镜=可独立执行的镜头任务

## 三、即梦智能画布操作路径

左侧功能栏「智能画布」→「上传图片」导入参考/素材 →「图生图」输入描述词 → **参考程度约55、参考方式选「轮廓边缘」** → 生成 → 消除笔/局部重绘/一键扩图修饰 → 导出进剪映加文案字幕。画布内可抠主体与场景融合："抠主体-摆场景-融图-扩图"一条龙。

## 四、七步实操工作流

1. **角色定稿（锚点图）**：抽卡选最佳主角图；正式项目上传三视图（可加表情差分）。要求每张只含一人、背景干净、面部清晰
2. **画布锁定特征**：挂载参考图并锁定五官/服饰/肤色参数，切换模型复用锚点
3. **场景锚点**：每主要场景1张基准图钉画布，角度扩展用一键扩图
4. **首镜定风格**：第一张分镜定画风/构图/光调，后续复述该图风格+挂同一参考（基于主角图一次连出四张风格统一图）
5. **逐镜连绘**：从左到右逐镜生成，上一镜成品=下一镜参考；视频化时尾帧链（供应商不返回尾帧时用FFmpeg从成片提取）
6. **修复与二次处理**：局部重绘修崩脸崩手；消除笔去多余元素；提示词节点反向出空场景图
7. **导出与视频化**：批量导出→Seedance/可灵（高质量静图+动作模仿远胜直接文生视频）→剪映

## 五、六条进阶技巧

1. **双参考机制**：同时挂"角色参考+构图参考"，参考程度55-65起步；人物走形调高、构图僵化调低
2. **先文生图后图生视频**：高质量静图+动作模仿，稳定性显著优于直接文生视频
3. **版本管理**：同分镜抽4张留1张，废稿留画布角落当"负面参考"
4. **资产化**：角色/场景/道具分区命名管理，跨集复用（含年龄/变装衍生形态）
5. **ComfyUI打通**：ComfyUI-Seedance节点接入即梦API，角色资产批量生产
6. **比例一次定死**：画幅/分辨率项目创建时确定；整集尾帧链串联保证衔接

### 新增实操技巧

1. **提示词强制关联**：用方括号显式命名角色（[林晚]），配 same / matching / identical 锁特征；关键一致性属性（脸型/瞳色）加权重 `(关键词:1.3)`。
2. **一致性六环链路**：角色身份基准 → 场景空间基准 → 资产沉淀 → 故事板调用 → 定位漂移修正 → 局部返工——2026年横评结论：决定一致性上限的不是单帧质量，而是链路完整性。
3. **定妆照法**：先出角色定妆照存为参考图，后续所有镜头统一上传；同时备场景参考图双挂载。
