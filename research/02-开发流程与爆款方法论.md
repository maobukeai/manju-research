# 02 · 开发流程与爆款方法论

> 研究组：行业与开发流程 · 网站对应模块：开发流程/爆款心法/制作清单

## 九阶段开发全流程

标准流程已收敛为：**立项选题 → 剧本 → 分镜脚本 → 角色场景设定 → 图像生成 → 视频动态化 → 配音配乐音效 → 剪辑成片 → 发布运营**。

### 阶段1 立项选题（2-3天）
- 男频主力：战神、逆袭（周榜10部中占9部）、赘婿、玄幻、系统流、末世+灵气复苏、诡异流、御兽
- 女频主力：甜宠、萌宝、穿越/穿书、重生复仇；复合题材（穿书+女扮男装+校园甜宠+炮灰逆袭）
- 2026转向：超六成S级爆款为IP改编；出海通用：霸总甜宠/契约婚姻/重生复仇/萌宝助攻
- 工具：DataEye/红果热榜/WETRUE、番茄/七猫热度榜
- 产出：选题评估表。避坑：避开已治理题材；先看结算规则再立项

### 阶段2 剧本（改编8-9天/季）
- 规格：60-100集、全剧80-120分钟、单集1-3分钟（红果约98秒-2分钟一个情绪闭环）
- 节奏公式：黄金3秒钩子 + 45-60秒黄金分割点反转 + 卡点留钩；"伏笔—反转—解密"闭环
- IAP端：前9集免费、第10集起单集付费（中文在线模式）
- 工具：豆包/DeepSeek改编 + 人工润色；即梦自动分镜拆解（约30秒）
- 避坑：版权头号风险走官方授权链；剧本要给分镜留画面空间

### 阶段3 分镜脚本（0.5-1天/集）
- 密度：单集2分钟40-60个镜头，平均<2秒，反转点可0.5秒
- 分镜表11字段：镜头号/景别/时长/画面描述/台词/角色/场景道具/运镜/生成方式/转场
- 脚本驱动批量拆分（LLM输出JSON）是产能关键
- 避坑：不标时长→后期节奏崩；不标景别→"PPT感"

### 阶段4 角色与场景设定（主角2-3天/人）
- 三视图（正/侧/背）+表情包+服装多套；反派配角也要设定图
- 40-80字角色描述卡一字不改；场景基准锚点图+扩图
- 一致性三级体系：①结构化Prompt约束（固定描述词表+种子）②参考锁定（多模态参考/LoRA/IP-Adapter/InstantID）③人脸检测修复兜底
- 避坑：中途换模型=风格漂移

### 阶段5 图像生成（60集约1-2周）
- 三档：新手=即梦；进阶=Midjourney；极致可控=SD+ComfyUI
- 抽卡可用率<30%说明模板有问题；单集算力80-100元
- 规格1080P起，9:16主+16:9备

### 阶段6 视频动态化（并行3-7天）
- 主力：Seedance 2.5（30秒多镜头/原生音频）、可灵3.0（运镜面板+首尾帧）、Vidu Q3（16秒声画）、海螺2.3
- 相邻镜头尾帧=下镜首帧（尾帧链）；流水线并行（3人日更10集）

### 阶段7 配音配乐音效（3-5天/季）
- 全行业第一痛点：46.7%用户不满"AI配音情感不足"→情绪标注词+分句控制+关键角色真人
- 三轨分离：对白/音效/BGM；BGM用Suno或可商用曲库

### 阶段8 剪辑成片（1-2天/10集）
- 剪映专业版（EditPilot提示词粗剪/Director Mode/AI踩点）
- 反转0.5秒精确落帧；字幕零错别字；双画幅+封面帧

### 阶段9 发布运营（持续）
- 矩阵：微信小程序起量→红果/抖音免费分发→独立App沉淀私域
- 投流占销售费用80-90%；日更1-2集；凌晨1-2点发布（经验之谈）
- 合规：AI标识+备案

## 爆款方法论（量化标准）

| 方法论 | 量化标准 |
|---|---|
| 黄金3秒 | 前3秒决定约80%去留；完播率权重最高 |
| 反转位置 | 单集45-60秒（黄金分割点）；反转镜头可0.5秒 |
| 伏笔闭环 | 伏笔—反转—解密；核心冲突前置 |
| 卡点 | IAA占71%（IAP 26%/IAAP 3%）；卡点服务完播与追更 |
| 标题封面 | 大字号精简文案；小红书系12-18字+情绪词≥30%+5-8标签 |
| 投流 | 占销售费用80-90%；漫剧投流日耗破400万；直投ROI约1.1、全域约1.8 |
| 算法差异 | 红果2分钟完播权重38% vs 抖音约22%；红果每集压98秒-2分钟 |
| 完播目标 | 15秒视频90%+；60秒视频50%+ |

**收益警示**：千播收益从60元跌至15-30元；万播从30-100元跌至5-10元；1.8亿播放仅结算18万元案例真实存在——爆款播放≠爆款收入。
