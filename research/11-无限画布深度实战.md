# 11 · 无限画布深度实战（2026-10）

> 本篇由主线研究直查（6次定向检索）· 网站对应模块：无限画布 · 补齐画布类工具的手把手实操层

## 一、六大画布工具实操指南

### 1. 即梦 · 智能画布（新手首选）
- **参数要点**：参考程度约55起步（人物走形调高、构图僵化调低）、参考方式选「轮廓边缘」；**构图漂移时把CFG锁在12-20**可锁定构图结构，避免随机漂移（什么值得买《分镜总跑偏？AI构图精准控制攻略》）
- **局部重绘**：涂抹选区后输入提示词仅重绘选中区域；**用专用修复模型效果优于普通生图模型**（博客园 day31 实测）；消除笔/图像扩展（扩图）在同一画布内闭环
- **分镜批量**：画布内可拖拽调整镜头顺序与重绘区域，批量分镜规划
- **角色锚定**：先生成三视图/定妆照钉在画布作"角色锚点"，后续图生图链式引用同一锚点；提示词中角色名称与关键外貌描述措辞固定不改（"提示词锚点"）

### 2. 剪映Hub（成片最短链路，2026-09-20发布）
- **结构**：无限画布 + 多轨编辑器 + 智能创作Agent「剪映助手」+ 移动端「小映」；AI Ultra订阅合并创作额度
- **四种基础节点**：**Idea（创意）/ Story（故事脚本）/ Image（图像）/ Video（视频）**
- **三种起点**：一句话、一段参考视频、一份文档——在画布上梳理脚本再展开创作
- **杀手级特性**：画布内调用即梦等模型生成后，**点一下直接跳转多轨剪辑器**，AI生成与AI剪辑连成流水线，免下载导出

### 3. 可灵 · 灵动画布（一致性最强）
- **Agent模式（2026-01-05上线）**：智能分镜 + 镜头多角度拓展 + 多轮对话编辑 + 一键批量生成，"短片创作一步到位"（可灵官方更新公告）
- **一致性**：多图参考功能升级，**角色/主体/场景一致性提升102%**；新增局部内容/特定区域参考；画布内可直接多图参考生视频
- **协作**：无限可视化空间 + 智能创作辅助 + **多人实时协作**的一站式工作台（团队分镜会议利器）
- 教程：虎课网《灵动画布-Agent 可灵2026新版教程》系列

### 4. 星流Agent（Lovart中文版，AI导演台）
- **形态**：左侧无限画布 + 右侧对话框，"用嘴设计"——自然语言驱动全链路（出图/出视频/品牌方案）
- **本地化**：中文语境与中文字体深度优化，国内直连（xingliu.art）；集成Seedream 4.0、Nano Banana等多模态模型
- **定位**：偏设计师工作流的Agent调度，适合把角色设定→分镜联排→出片放在一张画布统筹

### 5. Krea AI Realtime（风格探索）
- **Realtime Canvas 边画边生成**：即开即用、实时反馈最强；适合概念分镜、快速风格尝试
- 代价：灵活性受限；Krea1模型支持风格参考与定制训练，还开放MCP server接入60+工具

### 6. Toonflow（开源，技术团队）
- **无限画布 + AI Agent + 可视化工作流三合一**：支持图像/视频生成、智能分镜与短剧创作；可本地部署、自由接入模型（GitCode/GitHub开源）
- 关联：novelvids（Vue Flow故事版）同类；8K级无限画布依赖时空解耦设计（滑动时序窗口/全局特征缓存/分块特征融合），大画幅锁定一致性免拼接（SegmentFault）

## 二、锚点工作流最佳实践（综合）

1. **人物锚+场景锚先行**："先建人物锚和场景锚锁住外观，再分别生成"（MiniMax Design评测同款思路）
2. **图生图链式连绘**：以已生成图作为下一镜参考图，保证画风与人物延续；Nano Banana 2有《泰坦尼克号》100分镜画风人物特征高度一致的公开案例
3. **提示词锚点**：每镜固定角色名+关键外貌描述，措辞一字不改；"全身镜头"这类模糊指令改成构图边界的显式描述
4. **资产管理=版本管理**：角色定妆照、场景设定图、风格参考作为可复用资产纳入版本迭代管理（WorkRally已打通资产管理+版本迭代）；PixTV把流程拆为八环节（故事脚本→角色场景→分镜→关键画面→视频→声音→剪辑→资产复用），资产复用是效率核心
5. **废片率账**：废片率约50%时仍可能盈利——前提是用计算器算清三本账
