# 漫剧研究学习平台

持续追踪 **AI漫剧（动态漫画短剧）** 最新开发流程、工具栈、运镜语言、无限画布工作流、大模型应用与变现政策的研究项目，并把研究成果做成可视化学习网站。

## 快速开始

```bash
# 方式一：直接双击打开 index.html（无需服务器）
# 方式二：本地服务器（推荐）
cd 漫剧研究
python -m http.server 8410
# 浏览器访问 http://127.0.0.1:8410
```

## 前端 v2 特性

- **设计系统 v2**：极光渐变背景 + 网格纹理、玻璃拟态顶栏、统一卡片/阴影/圆角体系、SVG 线性图标导航
- **命令面板**：`Ctrl+K` 打开，支持模块跳转、快捷操作（切主题/随机灵感/看收藏/复制链接）、跨模块内容检索，含最近访问记录
- **三态主题**：跟随系统 / 浅色 / 深色循环切换，View Transition 圆形扩散过渡动画，首帧无闪烁
- **全局搜索**：`/` 键聚焦，结果关键词高亮 + 键盘导航
- **收藏系统**：工具库、运镜宝典、提示词模板三处均可收藏（localStorage 持久化），各自支持「只看收藏」一键筛出常用项
- **运镜演示控制台**：每格演示可暂停 / 变速（½×/1×/2×），滚动出视口自动暂停动画以省 CPU；演示场景在夜城/森林/雪原/霓虹四种光影间轮换（含雪粒/萤火粒子层）
- **区块内即时筛选**：工具库、术语表支持输入关键词即时过滤（名称/定位/技巧/释义），工具库另支持「评分优先 / 名称 A-Z」排序，提示词库支持「复制本组」一键导出整组模板
- **移动端表格优化**：宽表格首列吸附（横向滚动时第一列保持可见）+ 右侧渐隐滚动提示，随视口变化自动重算；全站表格斑马纹 + 行悬停高亮 + 首列强调
- **视觉升级 v2.1**：研究日志时间线卡片化（渐变版本徽章 + 「最新」脉冲标识 + 悬停平移，浅色主题适配）；题材热度分段条（渐变热度条替代星星，进场逐格动画）；术语卡渐变首字徽章；首页数据卡渐变数字 + 悬停浮起；Hero 标题渐变流光
- **移动端底部导航 v2.6**：窄屏（≤960px）底部毛玻璃快捷栏（总览/工具库/运镜宝典/提示词库/计算器/⌘面板），单触直达 + 安全区适配 + 当前项高亮
- **移动端目录抽屉**：目录按钮与面板在移动端变为底部抽屉形态，长内容页同样可快速跳节
- **卡片深链分享 v2.8**：工具 / 运镜 / 提示词卡片的 🔗 按钮一键复制深链（`#/tools?hl=名称`），任何设备打开自动滚动定位 + 紫色脉冲高亮该卡；首页新增「最新研究」横条（点击直达研究日志）；命令面板新增「复制我的收藏清单」（导出全部 ☆ 收藏为文本）
- **渲染兜底**：任一模块渲染抛错时显示友好错误卡（含错误信息与恢复提示），不再白屏；页脚新增「🖨 打印本页」；全站复制动作统一带 execCommand 降级
- **缓存策略 v2.3**：Service Worker 网络请求改用 no-cache 重新验证——修复浏览器 HTTP 启发式缓存吞掉研究更新的问题（改完 data.js 刷新即可见）
- **区块浮动目录 v2.4**：宽屏（≥1200px）右下角「☰ 目录」按钮，滑出面板列出当前区块全部小节，点击跳转（自动区分瞬时/平滑滚动）+ 滚动实时高亮当前小节
- **键盘快捷键体系 v2.5**：`?` 打开快捷键帮助面板（含全部快捷键速查）、`R` 随时随机抽提示词灵感（均已入命令面板快捷操作）
- **JSON 语法高亮**：代码块中的分镜 JSON 模板自动按 键名/字符串/数字/字面量 四色高亮（带 JSON 合法性校验，非 JSON 不处理）
- **搜索结果分组**：全局搜索结果按模块分组显示（分组标题吸附），定位更直观
- **运镜场景手动切换**：每格演示新增 🎨 按钮，可在夜城/森林/雪原/霓虹四种光影间手动循环切换（含粒子层同步替换）
- **阅读体验**：顶部阅读进度条、回到顶部按钮（带环形阅读进度指示）、首次访问欢迎引导、总览模块卡条数徽章、卡片进场编排动画、数字滚动动画
- **制作清单**：分组完成度徽标 + 一键复制进度摘要
- **无障碍与降级**：跳转正文链接、focus-visible 焦点环、aria 标注、`prefers-reduced-motion` 降级、打印样式
- **PWA**：可安装到桌面/手机，Service Worker 网络优先（每周更新即时可见）+ 离线回退
- **SEO**：完整 meta/OG 标签、theme-color 适配、manifest 图标

全局功能：`/` 键聚焦搜索（跨模块检索）、`Ctrl+K` 命令面板、明暗主题三态切换（跟随系统/深/浅）、阅读进度条、回到顶部、全站提示词一键复制、PWA 可安装。

## 数据更新机制

- 本项目配置了**每周自动研究任务**：追踪新工具版本、平台政策、爆款案例，更新 `js/data.js` 与 `research/` 档案，并在研究日志追加记录。
- 手动更新：改 `js/data.js` 对应数据段即可，网站无需构建。
- 数据截至 2026-10-02（v2.9），累计 480 次检索；平台政策变动极快，实操前以官方最新条款为准。
