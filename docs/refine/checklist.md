
要点说明：①"复制本组"只发 `data-copy="<regCopy 返回的索引>"`，复制动作由既有全局委托（app.js:1958-1959 `doCopy(+cp.dataset.copy, cp)`）完成，渲染函数内零新增 handler；`regCopy` 与视图函数同闭包（既有视图同款用法，见 app.js:566-568）；②"只看未完成"为原生 checkbox + CSS `:has()` 纯样式过滤，不进任何 JS 事件通道（全局 input 委托只认 `#sec-calc/#docSearch` 等固定目标，全局 click 委托的选择器均带属性限定，`chip mjx-checklist-tog` 无 `data-*` 属性不触发任何分支）；③勾选时 `.done` 类由既有委托维护，过滤随之即时生效，`refreshCkProgress` 计数不受 `display:none` 影响；④`mjxChecklistTodo` id 全页唯一。
